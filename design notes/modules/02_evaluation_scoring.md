# Proposal 2: Evaluation & Scoring Dashboard

## 1. Goal
Digitize the Technical and Financial Evaluation Committee (TEC) process, ensuring fairness and preventing bias.

## 2. PPA 2007 Control Requirements
- **Blind Scoring:** Technical scores must be finalized and locked BEFORE financial bids are opened.
- **Weighted Criteria:** Define scoring rubrics based on the tender category (Goods, Works, or Services).
- **Responsive Bid Rule:** Automatically flag bids that fail mandatory administrative or technical checks.

## 3. UI Flow
- **Committee Login:** Specialized view for assigned TEC members.
- **Bid Grid:** View all submitted bids; allow scoring per vendor per criteria.
- **Ranking Report:** Auto-generate the **Evaluation Report** summarizing the "Lowest Evaluated Responsive Bid."
